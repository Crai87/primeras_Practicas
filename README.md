# Poliestireno Alfa-Gamma

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una página web informativa para la empresa **Poliestireno Alfa-Gamma**, dedicada a la producción y distribución de termoplásticos.

El objetivo de la página es presentar información general de la empresa, dar a conocer sus diferentes áreas de trabajo, mostrar sus certificaciones y proporcionar medios de contacto para los visitantes.

## Características principales

La página web cuenta con las siguientes secciones:

- **Inicio:** Presentación de la empresa con una imagen principal y su nombre.
- **Nosotros:** Información general sobre la historia y actividad de Poliestireno Alfa-Gamma.
- **Áreas y servicios:** Descripción de las áreas de Producción, Sistemas y Logística.
- **Certificaciones:** Presentación de las certificaciones ISO 9001:2015, NOM ONNCCE y UL.
- **Contacto:** Información de ubicación, teléfono, correo electrónico y un formulario de contacto.

## Tecnologías utilizadas

- **HTML5:** Estructura y contenido de la página web.
- **CSS3:** Diseño, estilos, animaciones y adaptación a diferentes tamaños de pantalla.
- **Google Fonts:** Tipografía Roboto.
- **Font Awesome:** Iconos utilizados en los menús y secciones de la página.

## Instalación y ejecución

Para visualizar el proyecto de manera local, sigue estos pasos:

1. Descarga o clona este repositorio.
2. Descomprime la carpeta del proyecto, si es necesario.
3. Abre la carpeta en Visual Studio Code o en tu editor de código preferido.
4. Ejecuta el archivo `index.html` desde tu navegador web.

No es necesario instalar dependencias adicionales ni configurar una base de datos.

## Diseño y experiencia de usuario

La página cuenta con un diseño moderno y sencillo, utilizando una combinación de colores basada en la identidad visual de la empresa.

También incorpora:
- Menú de navegación con enlaces a las diferentes secciones.
- Menú desplegable para las áreas y servicios.
- Tarjetas informativas.
- Efectos y animaciones visuales.
- Diseño adaptable a dispositivos móviles y computadoras.
